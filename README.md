# SCT_SD_2
Project Title
Number Guessing Game
Description
This program generates a random number and asks the user to guess it. The program compares the user's guess with the generated number and provides feedback until the correct number is guessed.
Features
Random number generation
User input for guessing
Hint messages (Too High / Too Low)
Multiple attempts allowed
Displays total attempts taken
Technologies Used
Programming Language: C
Working
The computer generates a random number.
The user enters a guess.
The program compares the guess with the generated number.
If the guess is incorrect, a hint is displayed.
The process continues until the correct number is guessed.
How to Run
Compile the program.
Execute the program.
Enter your guess when prompted.
Continue guessing until you find the correct number.
Output
The program displays whether the guess is too high, too low, or correct, along with the number of attempts.
Conclusion
This project demonstrates the use of random number generation, loops, conditional statements, and user interaction in C programming.
